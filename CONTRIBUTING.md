# Contributions

Issues about documentation and read-only helpers are welcome. The owner-approved working TVW engine already exists; please do not submit speculative replacements for its parser, graphics engine or compiler. Any proposed `.tvw` examples need confirmation against the canonical 4.4.0 runtime and should not include proprietary application assets. Do not submit credentials, protected binaries, private source code or third-party code without redistribution rights.

Use a pull request, include reproducible evidence, and run `python -m unittest discover -s tests -v`. Public CI here only checks documentation and helper tooling; it is not a runtime certification.
