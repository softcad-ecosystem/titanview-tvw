# TVW adoption / Utilizare în aplicațiile SoftCAD

The owner reports production use of TitanView/TVW in **TitanPack**, **TitanArchive**, **TitanScann** and **TitanCAD**. These are **real deployed applications**, not hypothetical examples. This list is based on the owner's confirmation; this documentation-only repository does not attempt to extract their implementation from the application releases.

Application binaries and product source distributions remain managed separately via SoftCAD's release registry and download hosting. Neither their presence nor the use of TVW implies that the apps are open-source.
